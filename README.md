Twitter Scraper (Selenium)
This project is a scraper for Twitter, which uses Selenium to retrieve data from the site. Please be aware that using this code may violate Twitter's Terms of Service and local laws.

Warning!
Using this code may lead to account suspension. Twitter prohibits scraping data using methods that are not based on the official API.

We recommend using the official Twitter API for legal and safe access to data.

Requirements
Python 3.10.0

Selenium

ChromeDriver (or another WebDriver)

Installation
To install the dependencies, run the following command:

bash
pip install -r requirements.txt
